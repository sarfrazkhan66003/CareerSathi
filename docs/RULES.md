# Development Rules
- Do not modify existing behaviour; only add. Allowed edits to old files: nav/footer links, one stylesheet link, one script link, router include.
- Reuse existing helpers. Validate all input server-side. CSRF on every POST.
- Never fabricate mentors, partners, testimonials, statistics or guarantees.
- Label rule-based features honestly (not "AI" unless it is).
- Small functions; tests for logic; run `pytest` before finishing a task.
- Commit small, descriptive messages.
